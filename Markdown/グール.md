# グール AI 仕様

## 行動の流れ

```text
出現して数秒探索 → 地面に潜る → 近づいたプレイヤーを待ち伏せ
                                      ↓ 範囲内かつ壁に遮られない
                                地上に出て追跡・攻撃
                                      ↓ HP低下 / 時間経過 / 見失って探索中に数秒経過
                                    再び潜る
```

## 行動

1. **探索**：スポーン後は地上で数秒間、`EnemyAI` による通常の探索を行う。探索中は接触攻撃を無効にする。
2. **潜伏**：探索時間が終わるとその場で潜り、見た目・当たり判定・攻撃を止める。潜伏中は移動しない。
3. **待ち伏せ**：プレイヤー本体の `HB` を探し、設定距離以内かつ視線が壁に遮られていない場合に出現する。視線判定は `EnemyAI` と同じく、壁とプレイヤーを含む `LayerMask` で判定する。
4. **追跡・攻撃**：出現後は `EnemyAI` を有効にし、既存の追跡・移動と `EnemyAttack` の近接攻撃を使う。出現演出中は攻撃しない。
5. **再潜伏**：HP割合が閾値以下、地上時間が上限に到達、またはプレイヤーを見失って `EnemyAI` が探索を続ける猶予時間が終わった場合に潜る。プレイヤーが近くに居続ける間は再出現せず、一度反応範囲の外に出てから近づいた時に再び反応する。

## Inspector 設定

| 項目 | 初期値 | 内容 |
|---|---:|---|
| 最初の探索時間 | 3 秒 | スポーン後、潜るまで地上で探索する時間 |
| 待ち伏せ距離 | 5 | 潜伏中に出現を始める距離 |
| 視認距離 | 15 | 出現後、プレイヤーを見失ったか判定する距離 |
| 視線レイヤーマスク | 392 | `EnemyAI` と同じ初期値。壁とプレイヤーを含める |
| 出現時間 | 0.5 秒 | 出現してから追跡・攻撃を始めるまで |
| 最大地上時間 | 8 秒 | 出現してから潜るまでの上限 |
| 見失い後の探索時間 | 3 秒 | 視認できなくなってから潜るまで |
| 潜伏時間 | 0.5 秒 | 潜る演出の長さ |
| 再反応待ち時間 | 1 秒 | 再び出現できるまでの最低時間 |
| HP閾値 | 50% | 現在HPが最大HPに対してこの割合以下なら潜る |

数値は prefab の Inspector から変更できる。視線レイヤーマスクには、壁と `Player` タグが付いたプレイヤー HB のレイヤーを含める。

## コンポーネント構成

- `GhoulAI`：行動状態、待ち伏せ距離、視線判定、潜伏・出現を管理する。
- `EnemyAI`：探索、プレイヤー追跡、移動を担当する。潜伏中は無効化し、地上では有効にする。
- `EnemyAttack`：地上に出て攻撃可能になった後の近接攻撃を担当する。
- `EnemyHealth`：HP、死亡、ドロップを管理し、潜伏中のダメージを拒否する。

グールには `GhoulAI` と `EnemyAI` の両方を付ける。基本HP・移動・攻撃設定はゴブリンと同じにする。
