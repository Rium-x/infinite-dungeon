# 無限ダンジョン

Unity で制作している、個人開発のファンタジー・ダンジョン探索ゲームです。自動生成されるダンジョンを探索し、敵との戦闘やアイテム収集、装備・クラフトをしながら先の階層を目指します。

## ゲームについて

- BSP 方式のダンジョン生成と、用意した部屋テンプレートを使ったステージ構成
- 敵とのリアルタイム戦闘。敵には複数の AI や攻撃方法があります
- アイテム、装備、耐久度、インベントリ、クラフト
- HP・MPや状態効果を管理しながら探索
- マップやプレイヤー情報などのゲーム内 UI

本作は開発中です。機能や操作方法、バランスは変更されることがあります。

## 開発環境

- Unity `6000.5.6f1`
- Universal Render Pipeline
- Input System

## 起動方法

1. Unity Hub からこのリポジトリのフォルダーを Unity `6000.5.6f1` で開きます。
2. パッケージの読み込みが終わったら、`Assets/Scenes/TitleScene.unity` を開きます。
3. Unity エディターの Play ボタンで実行します。

ビルド設定にはタイトル画面とゲームプレイ用シーン（`Assets/Scenes/SampleScene.unity`）が登録されています。

## 操作

プレイヤーの移動はマウスクリックによる方向指定、またはゲームパッドのスティックに対応しています。攻撃やアイテム使用などの割り当ては Input System の `PlayerControls` とシーン内の UI を参照してください。操作割り当ては開発中のため、この README では固定のキー一覧を記載していません。

## 主なフォルダー

| パス | 内容 |
| --- | --- |
| `Assets/Scenes/` | タイトル画面とゲームプレイ用シーン |
| `Assets/Script/` | ゲーム進行、プレイヤー、敵、アイテム、UI などの C# スクリプト |
| `Assets/general/` | ゲームで使用する画像・Prefab・ステージデータなど |
| `Packages/manifest.json` | Unity パッケージ依存関係 |

## 開発メモ

Unity プロジェクト一式を Unity Hub から開いてください。`Library/` など Unity が生成するフォルダーはリポジトリに含める必要はありません。
